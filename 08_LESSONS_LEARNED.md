# 08 — LESSONS LEARNED (our own data)

1. **Joe Bart short ≈ 10k views** on @OneScrollMan was the early best — facecam reaction + instant jumpscare payoff.
2. **JasonTheWeen "most viral ranked" (46 s countdown): 203 views, 51.6% swiped away.** Cause: no captions for the first 7 s, wide/blurry 2nd shot, generic "most viral moments" header, too long. → Rule: captions at 0.0 s, payoff frame first, ≤ 35 s.
3. A new YouTube account's first Shorts can sit at 0 views: check Public, not "made for kids", no Reused-content/copyright restriction; don't delete/re-upload.
4. "Invalid video orientation" in Metricool/YouTube = non-1:1 SAR → fixed with setsar=1 + -aspect 9:16.
5. Hooks must be literally true (we rewrote "HE DID A CARD TRICK ON JASONTHEWEEN" → "JASONTHEWEEN'S CARD TRICK...").
6. Burned-in stream captions double up with ours → crop them out (h=950 crop from top).
7. Danesh v2 (8 s loop): replacing blurry shots with cutaways of the payoff (J-cuts) + progress bar made the clip dramatically cleaner — use cutaways whenever the speaker isn't on camera.
8. Campaign footage ≠ always usable: Gattouz had ~16 h of content but only ~4 clean English moments → scan transcripts + language first, edit second.
9. Owner posting from phone: always provide ready-to-paste text and Swedish UI navigation hints.
